# 八菽之囿

<div class="search-only">
八菽之囿 神明灵 首都 无 信仰 先祖崇拜 神王统治 区域 昉土 纵横水网 古代遗迹 统治者 东海伯 虞皞 慷慨 耐心 安于现状 虞皞 巫祝 神明灵早已忘却那覆灭故国的名字，忘却自己生前的名字，仅凭那残破的记忆与执念，化作倒影在废墟中游荡。虞皞于这迷幻的白雾中窥视着它们的徒劳，并为此落泪，于是祂以神明灵那残破的记忆化作“阴天子”，甘愿带领这群神明灵于这迷雾缭绕的泽国中建立起名为“八菽”的亡魂之城。神明灵们夺舍这山精水怪，化作光怪陆离的妖魔游荡于这水泽之间——对于凡人而言，这里是生者止步的禁地；而对于那些亡魂而言，这里则是它们彻底消散前的最后归宿
