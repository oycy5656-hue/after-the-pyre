# 全部笔记

这里是笔记的入口。按你的习惯建目录——按主题、按项目、按时间都行，只要在 `docs/.vitepress/config.mts` 的 `sidebar` 里登记。

## 推荐的组织方式

::: tip 按主题分
`docs/notes/技术/`、`docs/notes/读书/`、`docs/notes/生活/`，每类一个 `index.md` 当目录页。适合长期积累。
:::

::: tip 按时间分
`docs/notes/2026/11-13-某件事.md`。适合日志、周报、实验记录。
:::

::: tip 一页一概念
像 Obsidian 那样，每个概念一个短页面，页面之间大量互链。检索时命中率高。
:::

新建 `docs/notes/xxx.md`，然后在这页加一行链接，再到 `sidebar` 里登记。三步，一分钟。
