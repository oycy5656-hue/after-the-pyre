# Markdown 速查

## 标题

```md
# 一级标题（每页一个，作为页面标题）
## 二级标题
### 三级标题
```

标题层级不要跳级，右侧的"本页目录"就是从二、三级标题生成的。

## 文本

```md
**加粗**  *斜体*  ~~删除线~~  `行内代码`
```

## 列表

```md
- 无序项
- 无序项
  - 嵌套项

1. 有序项
2. 有序项
```

## 链接与图片

```md
[站内链接](/guide/writing)
[外部链接](https://example.com)
![图片说明](/logo.svg)
```

## 引用

```md
> 引用段落
>
> 可以有多段
```

## 分割线

```md
---
```

注意：文件最开头的两行 `---` 是 frontmatter，不要和分割线搞混。

## 表格

```md
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
```

## 代码块

````md
```js
console.log('hello')
```

```js{1,3}
第一行高亮
第二行
第三行高亮
```
````

## 提示框

```md
::: tip 标题可选
内容
:::

::: info
内容
:::

::: warning
内容
:::

::: danger
内容
:::

::: details 点我展开
内容
:::
```

支持自定义标题，写在类型后面：`::: tip 我的标题`。内容里可以放代码、列表、甚至嵌套别的提示框。

## 任务列表

```md
- [x] 已完成
- [ ] 未完成
```

## 脚注与锚点

标题会自动生成锚点，`## 我的小节` 对应 `#我的小节`（中文同样可用）。跨页引用小节写成 `/guide/writing#常用写法`。
